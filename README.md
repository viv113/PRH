# PRH

Paper Reading Homework：先自己读论文和填作业，再由AI依据原文批改，讨论结束后留下重点总结。

## 使用流程

1. 提供论文PDF；有补充材料时一起提供。每篇先核查期刊影响因子及年度、中科院大类分区及版本，并给来源与查询日期；JCR分区另列，不能混用。默认优先推荐中科院一区，或影响因子较高且与课题相关的论文；满足其一即可，不擅设固定影响因子门槛。影响因子与分区分别标明，未核实分区不冒充一区；用户明确指定的论文可说明指标后继续阅读。
2. AI核查原文，按论文特点定制第一份Word作业，默认2—3页、以主图为线索，以具体短题为主；综合思考与跨图串联题全篇仅保留最关键的1—2道，不在一道题中堆叠多个任务，不附答案。
3. 自主阅读，在Word中填写后提交；不懂可写“？”，缺失信息可写“未报告”。
4. AI核对原文，在提交的Word对应题目和表格内直接批改，保留原答案并另存批改版：红字修正错误，黑字加黄色高亮补充遗漏及简短正确答案，不只指出错误。随后继续答疑。
5. 明确说“这篇读完了，请总结”后，AI生成第二份独立Word，提炼论文主线、预习理解如何被修正或深化、已吸收的内容、可借鉴方法和剩余疑问。不覆盖原作业。

## 文档样式

未填写作业及最终总结使用全黑文字，无装饰和底色；批改版使用红字纠错、黄色高亮补充。主标题楷体18磅，小标题楷体12磅；正文、提示、表格和答题区全部宋体11磅。短答区通常留两行，内容优先于美化。总结默认约300—500字，通常一页。

## 安装

将本仓库的`SKILL.md`放入Codex技能目录中的`paper-reading-homework`文件夹。默认位置为`~/.codex/skills/paper-reading-homework/SKILL.md`；设置了`CODEX_HOME`时使用该目录下的`skills`。

也可将仓库克隆到上述技能文件夹，注意文件夹名称仍为`paper-reading-homework`，仓库名称为PRH不影响使用。让客户端重新加载技能；未显示时重启客户端。

## 调用示例

“用 $paper-reading-homework 为这篇论文生成2—3页Word精读作业。我先读、先填，你收到后批改。”

“这是填写后的作业，请核对论文批改；我们先讨论，结束后再生成第二份总结Word。”

## 能力与边界

需要运行环境支持原文和图像读取，以及可编辑Word生成。技能文件本身不包含PDF解析器、字体或Word生成工具；无法读取或生成时须如实说明。核查原文不等于保证论文结论正确；AI讲过不等于用户已掌握。

适用于以主图为线索的科研论文阅读，不将普通问答强制变为作业。不附带论文全文、个人作答和研究数据。

GitHub修改不会自动同步到本地复制安装版：需重新下载替换；克隆安装版可在备份个人修改后使用`git pull`更新。
